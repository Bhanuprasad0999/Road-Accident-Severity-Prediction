# 🚗 Road Accident Severity Prediction

A machine learning web application developed using Python, Random Forest Classifier, and Streamlit.

## 🚀 Live Demo

[🌐 Click Here to View Live Application](https://road-accident-severity-prediction-84jz.onrender.com/)

## 🛠️ Technologies Used

- Python
- Random Forest Classifier
- Scikit-learn
- Pandas
- Streamlit
- Joblib
- Render

## ✨ Features

- Predicts road accident severity
- Uses 16 input features
- Displays Low, Medium, and High severity alerts
- Shows model prediction confidence when available
- Provides road safety recommendations
